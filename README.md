# MuffinLab Modpack

MuffinLab 服务器 **Mechanomania Aeronautics（机械动力·航空学）** 的客户端模组集合。
用途是让服务器成员把本地客户端的模组快速同步到与服务端一致（配合 Muffin Launcher 使用）。

- 游戏版本：Minecraft 1.21.1
- 加载器：NeoForge
- 模组数量：见「模组统计」一节，或用根目录下的脚本即时统计

## 模组统计

仓库根目录提供了统计脚本，不需要安装任何依赖：

```bash
python count-mods.py            # 概览：启用/禁用数量、总体积、体积最大的几个
python count-mods.py --list     # 在上面基础上，额外列出全部模组文件名
python count-mods.py ./mods     # 也可以指定别的目录
```

当前统计（2026-09-28 快照）：**192 个模组，合计约 315.4 MB**，平均单个 1.64 MB。
实际数字以运行脚本为准。

- 已启用模组（`*.jar`）与已禁用模组（`*.jar.disabled`）各自的数量
- 总占用体积与平均体积
- 体积最大的若干模组（便于排查哪个包最占空间）

> 提示：日常同步建议直接用 [Muffin Launcher](https://github.com/AlleinMuffin/muffinlab-site)
> 的整合包同步功能；手动安装的话，把 `mods/` 目录里的文件放进游戏目录的 `mods` 文件夹即可。
